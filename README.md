# Biblioteca Comunitária — leitor digital

Primeiro protótipo da Biblioteca Comunitária, com uma experiência de leitura digital para *Poemas Pesados Demais para Serem Lidos Apenas uma Vez*, de Joad Lima.

## Abrir localmente

1. Abra esta pasta no Visual Studio Code.
2. Inicie o Live Server pelo arquivo `index.html`.

## Recursos

- Capa abre o leitor expandido sobre a mesma tela.
- 37 páginas digitais recortadas pela área de corte do PDF.
- Animação de folha, som opcional e controles de navegação.
- Avanço por setas, clique, rolagem do mouse e gesto de deslizar.
- Sumário, adaptação para celular e salvamento da última página no dispositivo.

As páginas em branco de impressão foram removidas da sequência digital. A numeração impressa continua visível nas páginas originais.
